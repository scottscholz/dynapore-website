# dynaporetech.com

The DynaPore website. Plain HTML and CSS, built by one small Python script and hosted on Netlify.
Every push to `main` goes live automatically within about a minute.

## Editing text

Each page lives in `src/pages/`. Open the file, change the words, commit. That is all.

| Page | File |
| --- | --- |
| Home | `src/pages/index.html` |
| LNP application | `src/pages/applications/lipid-nanoparticles.html` |
| AMP application | `src/pages/applications/antimicrobial-peptides.html` |
| Sensors application | `src/pages/applications/membrane-sensors.html` |
| How MemChip works | `src/pages/technology/memchip.html` |
| Surface-matched slides | `src/pages/technology/slides.html` |
| Team | `src/pages/team.html` |
| Contact / trial request | `src/pages/contact.html` |
| Impressum, Datenschutz | `src/pages/imprint.html`, `src/pages/privacy.html` |

The header (menu, early-access banner) is `src/partials/header.html`; the footer is `src/partials/footer.html`.
Change them once and every page updates.

The first line of each page sets its browser title and Google description:
`<!--meta {"title": "...", "description": "...", "nav": "applications"} -->`

## Shortcuts you will see in the pages

| Tag | What it does |
| --- | --- |
| `{{/contact/#request}}` | Link to another page on the site |
| `{{@assets/img/photo.jpg}}` | Link to a file in `assets/` |
| `{{vid:FILE\|POSTER\|MOBILE}}` | Silent looping video from `assets/media/` |
| `{{film:FILE\|POSTER\|MOBILE\|portrait}}` | Same, with an optional class |
| `{{svg:name}}` | Diagram from `src/partials/svg/` |
| `{{ph:DATA\|description}}` | Striped placeholder box: replace with real content |
| `{{tbc:text}}` | Small teal "to confirm" marker: remove when confirmed |

Search the pages for `{{ph:` and `{{tbc:` to find everything still open.

## Images and video

Put files in `assets/img/` or `assets/media/`, then reference them, for example
`<img src="{{@assets/img/lnp-data.png}}" alt="LNP formulation comparison">`.
Keep videos silent, H.264 MP4 with faststart, and under about 10 MB.

## Diagrams

The diagrams are generated by `tools/gen_svgs.py` (run `python3 tools/gen_svgs.py`). Edit labels there, not in the SVG files.

## Building locally (optional)

```
python3 build.py            # production site into dist/
python3 build.py --preview  # relative links into preview/, for opening files directly
```

Netlify runs `python3 build.py` itself (see `netlify.toml`), so you never need to build before pushing.
